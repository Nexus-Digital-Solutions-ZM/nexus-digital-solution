Deep Dive: Nexus Flow OS

Case Study 002
Nexus Flow OS — Multi-Branch Fuel & Business Operations Platform
In Active Development · Pilot Onboarding
Brief & Challenge
Fuel retailers running multiple branches lack real-time visibility into shift-level cash, stock, and variance — most still rely on paper dip books and end-of-day reconciliation.
Attendant handovers and cash drops needed a live, auditable trail instead of a manual book checked once per shift.
Mobile money is now a standard payment method at the pump — the platform needed native support for the two dominant Zambian rails, not a bolt-on.
Architecture had to accommodate stations at very different maturity levels — from fully manual dip readings to future forecourt hardware integration — without a rebuild.
Tech Stack
Next.js TypeScript FastAPI PostgreSQL Redis Docker nginx
Solution & Execution
Built a flexible Nozzle model that replaces hardcoded pump-meter columns — the same schema scales from a single-pump site to a multi-branch network.
Designed a timezone-aware dynamic shift-boundary and dip-reading gate system, so shift handovers are enforced by the platform rather than trusted to a paper log.
Implemented self-healing inventory reconciliation with threshold-based variance detection, automatically flagging incidents instead of waiting for a manual month-end review.
Added a mobile money payment modal for attendants covering Airtel and MTN — the two payment rails already in daily use at Zambian filling stations.
Built an executive dashboard showing true gross margin with fuel cost factored in, plus a branch-scoped finance page for revenue and expense tracking.
Containerized the full stack with Docker Compose and nginx for consistent, repeatable deployment across branch sites.

Deep Dive: TZDA

Case Study 001
The Zambia Debate Association — Official Website
Live at thezdebate.org
Brief & Challenge
TZDA needed a professional national web presence to establish credibility as Zambia's official debate body.
Required membership registration, document distribution, event listings, and contact functionality — all in one site.
No existing infrastructure — built entirely from scratch including branding integration, form backend, and file hosting.
Had to be mobile-first, fast-loading, and maintainable without a CMS or technical team on the client side.
Tech Stack
HTML5 CSS3 Vanilla JS Formspree Google Drive API Google Analytics Vercel
Solution & Execution
Built a single-page application with JS-driven page switching — no reload, no framework dependency, zero build tooling required.
Designed a bespoke green-and-gold brand system matching TZDA's national identity with custom CSS variables throughout.
Integrated Formspree for membership applications and contact messages — submissions route directly to the association's inbox.
Hosted constitution PDF on Google Drive with direct download and preview links — no server storage costs.
Added Google Analytics (G-tag) for visitor tracking and reporting to leadership — verifiable data for board reports.
Deployed on Vercel with instant global CDN — sub-second load times across Zambia on mobile networks.
